# Replacing the sample product photos

The store originally used Picsum, which returns unrelated photographs. This image kit gives every product a local image path. It also keeps image changes separate from the rest of your DynamoDB records.

The four Desk & Studio product images and its category banner are already included. The remaining images are downloaded from Wikimedia Commons, with a credit file generated in `docs/IMAGE_CREDITS.md`.

## Use the kit

1. Extract the kit into your project root. Keep its `scripts` and `public` directories in place.
2. Apply `catalog-images.patch` with `git apply --check catalog-images.patch` and then `git apply catalog-images.patch`.
3. Run `node scripts/download-catalog-images.mjs` while connected to the internet. If a download fails, review the error and rerun; files that already exist are skipped.
4. Open the images in `public/images/products/` and `public/images/categories/`. **Please review each image before using it.** The freely licensed photos illustrate the product type, but a few differ from the sample products' stated material, exact quantity or appearance. You can replace any file with a more accurate, properly licensed picture; keep the same filename and format.
5. Keep Docker and DynamoDB Local running. Preview the database change with `node --env-file=.env.local scripts/update-catalog-images.mjs`.
6. If the dry run succeeds, execute `node --env-file=.env.local scripts/update-catalog-images.mjs --apply`.
7. Refresh the storefront. Check a product page, the product grid, the four category cards, cart and wishlist images.

Do **not** run `npm run db:seed` to update pictures. It writes entire product records, potentially resetting stock and prices. The image updater only updates the `images` field on each existing product and the `image` field on each existing category. It also saves their previous image values under `image-backups/`, which Git ignores.

## Verify before committing

Run `npm run typecheck`, `npm test`, `npm run lint` and `npm run build`. If all checks pass, review `git status`, then stage `scripts/seed-data.ts`, `.gitignore`, `scripts/download-catalog-images.mjs`, `scripts/update-catalog-images.mjs`, `scripts/image-sources.mjs`, `public/images`, `docs/IMAGE_CREDITS.json`, `docs/IMAGE_CREDITS.md` and this file. Commit only after the image files have been reviewed and the update has completed.

The credits generated by the downloader identify each Wikimedia source, photographer and license. Some photos are shared under Creative Commons Attribution-ShareAlike terms. Preserve the required credit and comply with the individual license when modifying or redistributing them.

All product descriptions and prices remain sample data. These photographs are representative images, not confirmation that a particular physical product or brand exists.
